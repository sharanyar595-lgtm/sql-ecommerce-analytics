# ShopSimple SQL Analytics (SQL Server)

A SQL project that models a small e-commerce store (customers, products, orders) and answers business questions using **T-SQL in SQL Server**. It has a beginner set of queries and an advanced set covering RFM segmentation, customer lifetime value, monthly trends, and cohort retention.

## Tools
SQL Server (Express/Developer) and SQL Server Management Studio (SSMS)

## Files
| File | Purpose |
|---|---|
| `01_setup.sql` | Creates the `shop_simple` database, 3 tables with primary/foreign keys, and loads 20 customers, 12 products, and 200 orders |
| `02_beginner_queries.sql` | 8 queries: filtering, sorting, JOINs, GROUP BY, aggregates, TOP |
| `03_advanced_queries.sql` | CTEs and window functions: monthly revenue with MoM growth (`LAG`), RFM scoring (`NTILE`), CLV, repeat vs one-time customers, cohort retention, top product per category (`ROW_NUMBER`) |

## Database structure
```
customers ──< orders >── products
```
- **customers**: customer_id, name, city
- **products**: product_id, product_name, category, price
- **orders**: order_id, customer_id, product_id, quantity, order_date

## How to run
1. Open `01_setup.sql` in SSMS and run it (F5).
2. Open `02_beginner_queries.sql` and run each query one at a time.
3. Open `03_advanced_queries.sql` and run each lettered section as one block.

## Key findings
- **Category mix:** Clothing generated 47.3% of revenue (₹295,751), followed by Electronics at 25.2%. Stationery contributed only 3.2%.
- **Product concentration:** Running Shoes alone brought in ₹185,447, about 30% of total revenue, so one product drives a large share of sales.
- **Customer value:** The top customer, Priya Nair, spent ₹76,042 across 26 orders (12% of revenue). 17 of 19 buyers (89.5%) are repeat customers.
- **Seasonality:** Monthly revenue is volatile, peaking in July 2025 (₹71,555) and dropping to ₹7,689 in February 2026.
- **RFM:** Champions (4 customers) account for about 34% of revenue, while At Risk customers (3) hold about 23%, making them the best target for win-back offers.

## Skills demonstrated
Relational design (PK/FK, constraints), JOINs, GROUP BY and aggregates, CTEs, window functions (`LAG`, `NTILE`, `ROW_NUMBER`, running totals), customer segmentation, and cohort analysis.

## Note
The data is synthetic sample data generated by a fixed formula, so results are repeatable.
